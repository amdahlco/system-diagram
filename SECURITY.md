# Security

Please report a security problem privately, not in a public issue. On this repo's GitHub page,
open the **Security** tab and choose **Report a vulnerability**. Only the maintainers see the
report.

Useful details: what an attacker can do, the input or steps that show it, and the version (the
commit) you tested.

Fixes go into the latest release and `main`; older releases are not patched.

The page this skill builds puts data and theme values into HTML, so problems such as script
injection through a data file or a theme are in scope.
