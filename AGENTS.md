## Glossary

- Read https://github.com/amdahlco/amdahl-system-map/blob/main/GLOSSARY.md before you name anything new.
- Use the glossary term for a thing the glossary names.
- Never use an Avoid word in a new table, column, type, field, enum, exported function, API field or UI string.
- If the code needs a concept the glossary lacks, open a PR on amdahlco/amdahl-system-map that adds the row first.
- Link the glossary PR from the code PR.
- The "Glossary" check blocks the code PR until that row is merged.
- Do not rename an existing identifier for the glossary unless the task says so.
- Put a technical word with no domain meaning in `.glossary/allow.txt`, sorted, one per line, in the same PR.
- The "Glossary" check runs on every PR, including PRs into `development`.
